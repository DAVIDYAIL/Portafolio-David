\# Portafolio David Muñoz



Proyecto desarrollado para la actividad EPE1 del módulo Desarrollo Web II.



\## Tecnologías utilizadas



\- HTML5

\- CSS

\- Bootstrap

\- JSP

\- MySQL

\- Apache Tomcat

\- Git y GitHub



\## Estructura principal



\- index.html: página de inicio

\- proyectos.jsp: muestra proyectos almacenados en MySQL

\- habilidades.jsp: muestra habilidades almacenadas en MySQL

\- experiencia.html: información de experiencia

\- contacto.jsp: formulario de contacto

\- css/estilo.css: estilos del sitio

\- SQL/: script para crear la base de datos



\## Ejecución del proyecto



El proyecto utiliza Apache Tomcat para ejecutar las páginas JSP.



La base de datos utilizada se llama:



portafolio



El script necesario para crear las tablas y datos iniciales se encuentra en la carpeta SQL.



Para la conexión con MySQL se utiliza un archivo local config.jsp, el cual no se incluye en GitHub para evitar publicar la contraseña de la base de datos.
